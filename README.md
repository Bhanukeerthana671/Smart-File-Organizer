# Smart File Organizer

A Python automation project that automatically organizes files into folders based on their file type.

## Features

- Organizes Images (.jpg, .jpeg, .png, .gif)
- Organizes Documents (.pdf, .docx, .txt, .pptx)
- Organizes Videos (.mp4, .mkv, .avi)
- Organizes Music (.mp3, .wav)
- Organizes Excel files (.xlsx, .csv)

## Technologies Used

- Python 3
- pathlib
- shutil

## Project Structure

Smart-File-Organizer/

## How to Run

python organizer.py
